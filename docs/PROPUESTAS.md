# Propuestas para valorar

Estas funciones NO están implementadas ni aprobadas como requisitos.

1. Mensajes en español y `/generation status` con generaciones abiertas, cerradas y estado de cada filtro. Prioridad alta: facilita soporte y detectar inicialización incompleta.
2. `/generation set gen1 gen2` para sustituir la lista completa en una operación, y autocompletado que sugiera únicamente cambios aplicables. Prioridad media.
3. Calendario de desbloqueo opcional: fechas absolutas, zona horaria explícita, persistencia y aplicación única tras reinicios. No activar un calendario sin acordar las fechas.
4. Registro de cambios con ejecutor, hora, generaciones anteriores y nuevas. Útil para staff.
5. Excepciones por especie o forma, con precedencia explícita respecto a la generación. Requiere decidir cómo clasificar formas regionales.
6. Vista previa de especies que se habilitarían antes de cambiar la lista; considerar datapacks y recargas.

Mantener primero una versión estable de aparición por generaciones. Bloquear crianza, evolución o intercambios sería otro alcance y necesita una decisión explícita: puede afectar Pokémon ya pertenecientes a jugadores.
